Eigen project, Leiden

Persoonlijk
jun. 2025 - Heden

Een project dat ik zelf ben begonnen om mijn financiën in kaart te brengen. Ook ben ik in gesprek met een budgetcoach om deze software uit te brengen, voor studenten die graag meer inzicht in hun eigen financiën willen.

Deze app zal geen data van andere gebruikers opslaan en er hoeft ook niet betaald te worden voor de software.

Slagtvelt Ticketsysteem & Ticketscanner

Slagtvelt festival, Ruinen

Chef ICT & Hoofd Automatisering
apr. 2024 - feb. 2026

Ik heb voor drie vrienden van mij het Slagtvelt project gedaan. Ze wilde graag een ticketsysteem hebben om echt inzicht te hebben in hoeveel mensen er kwamen en wie er al betaald had.

Hieruit is een CRUD applicatie voortgekomen. Met deze applicatie kan de organisatie: gasten toevoegen, e-mails versturen met een betaallink en de tickets. Ook heb ik een QR-code scanner gebouwd om de tickets in te scannen. De mobiele app heeft geen internet nodig om te kunnen functioneren.

  • Python Django

Hotel bookingsysteem

Hogeschool Leiden, Leiden

INKCOEX
nov. 2024 - jan. 2025

Voor een keuzedeel op school mocht ik een eigen project bouwen hiervoor heb ik besloten om in .NET een Hotel bookingsysteem te bouwen. Ik had een MVC front-end en een RestAPI als back-end. Maar ik wilde het mij wel lastiger maken door de authenticatie zelf te doen, zodat ik er meer over zou leren. Dat is mij dus uiteindelijk gelukt het was wel lastig om dit te realiseren.

Wel kreeg ik als feedback van de docent, dat het een erg vet project is en dat het gaaf is dat ik de authenticatie zelf gebouwd heb, alleen dit moet ik nooit meer doen. Aangezien .NET zelf de authenticatie voor je kan doen zonder dat jijzelf continue op de nieuwe security nieuwtjes moet letten.

  • .NET
  • MVC
  • RestAPI
